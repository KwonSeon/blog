# 회원 공개 채팅

사용자 요청: 회원끼리 함께 사용하는 공개 채팅방. `/chat`의 기본 **자유 대화** 방은 로그인한 모든 회원에게 공개된다. 비로그인 사용자에게는 메시지를 제공하지 않으며 검색엔진 색인을 막는다. 비공개 1:1 문의, 익명 채팅, 첨부파일, 외부 메시지 발송은 이 범위에 포함하지 않는다.

## 사용과 보관

- 내 계정 → 회원 채팅에서 최근50개를 시간순으로 보고 이전 대화를50개씩 조회한다. 이전 페이지를 보고 있을 때 새 메시지가 와도 최근 페이지로 강제 이동하지 않는다.
- 메시지는 평문 최대2000자다. HTML을 실행하지 않는다. 이메일 형태의 표시 이름은 일반 회원 명칭으로 대체한다.
- 본인 또는 명시적으로 연결된 블로그 작성자가 메시지를 삭제할 수 있다. 삭제 시 본문·표시 이름을 즉시 지우며 삭제 표시는 대화 순서에 남긴다. 소유 권한은 서명된 subject와 merged_subjects로 확인한다. 작성자 권한은 기존 서버 바인딩만 사용한다.
- 최근90일의 이력만 조회된다. 보관 작업은 오래된 행을 시간당 최대1000개씩 제거하므로, 대량 이력이 있으면 물리적 제거가 더 늦을 수 있다. 삭제된 메시지의 subject/요청 해시는 중복 요청과 권한 확인을 위해 이 보관 주기 동안 남는다.
- 계정별1초 간격, 분당30건·일500건으로 제한한다. 한 요청키에 다른 본문을 재사용하면 거절한다. 응답이 유실돼도 같은 요청키로 재시도하면 기존 메시지를 반환한다.

## 연결과 배포

`BLOG_CHAT_ENABLED`는 기본false다. API의 `BLOG_CHAT_ORIGIN`에 브라우저의 정확한 HTTPS origin(끝 슬래시 없이)을 설정한 환경에서만 켠다. 원본 DB와 공통 Auth는 환경별로 분리한다. V11은 추가 테이블만 생성하며 기존 API와 호환된다.

브라우저는 HttpOnly `blog.access` 쿠키를 `/api/chat/ws`의 WebSocket handshake에만 사용한다. 일반 HTTP API는 기존 BFF→Bearer 경로를 유지한다. WebSocket은 정확한 Origin과 유효한 JWT가 필요하며 쿠키 인증을 다른 API에 확대하지 않는다. 토큰을 URL이나 JavaScript에 노출하지 않는다.

STOMP1.2의 `/topic/member-chat` 구독만 허용하고, 클라이언트의 SEND 및 다른 경로 구독을 거절한다. 메시지 쓰기·삭제는 HTTP API에서 검증하고 트랜잭션 커밋 뒤 내용 없는 변경 신호만 보낸다. 세션당 구독1개, 계정별 연결5개, 서버별 연결200개, 프레임8KiB와 전송 버퍼16KiB 한도를 적용한다. 만료된 토큰의 연결은 최대10초 주기로 닫으며, 구독 시점에도 만료를 검사한다.

브라우저는 재접속과15초 주기 이력 갱신을 병행한다. 따라서 블루그린의 서로 다른 인메모리 브로커에 연결되거나 실시간 신호를 놓쳐도 DB 조회로 복구한다. 신호는 전달·읽음 영수증이 아니며, 실시간 전파의 최대 지연을 보장하지 않는다. 최근50개보다 대화가 많으면 이전 페이지로 계속 확인할 수 있다.

개발 Tunnel은 정확한 `/api/chat/ws` 경로만 개발 API에 연결하고 나머지는 기존 웹으로 보낸다. 운영 Nginx는 같은 경로에 HTTP1.1 Upgrade와 기존 release API 변수를 사용한다. private runtime·DNS·Tunnel 자격정보는 저장소에 포함하지 않는다. 연결이 만료/중단되면 다시 연결하므로 배포 중 소켓 자체의 영구 유지를 주장하지 않는다.

검증은 합성 개발 계정과 합성 메시지만 사용한다. 실제 사용자에게 메시지를 보내거나 운영 채팅 기록을 생성하지 않는다.

기술 근거: [Spring WebSocket 인증](https://docs.spring.io/spring-framework/reference/web/websocket/stomp/authentication.html), [Spring WebSocket 보안](https://docs.spring.io/spring-security/reference/servlet/integrations/websocket.html).
